# 组件规范与无障碍说明编辑台（sologsb-1028）

面向设计系统维护者的组件契约编辑台。项目从零搭建，不是单页占位稿；组件、属性、状态、键盘行为、读屏说明、禁用场景和代码示例均使用真实数据模型，并自动保存到浏览器 `localStorage`。

## 功能

- 组件目录与全文搜索：可搜索组件名称、属性、键盘行为、读屏说明和示例代码。
- 分组编辑器：概述、属性与状态、无障碍、关联示例、版本与迁移五个工作区。
- 规范校验：检测重复属性、缺少键盘/读屏说明、空示例、失效属性引用和交互契约变化。
- 失效传播与迁移：修改交互签名、删除属性或更新组件契约后，关联示例会标记为待迁移；迁移操作可清理已删除属性引用并更新版本。
- 版本差异：保存快照后可比较字段、属性与示例变化；保留最近 12 个快照。
- 多标签页顺序合并：每次编辑都是一条可重放操作，保存在本地操作日志中。切回标签页或收到其他页改动时自动重放合并；同一属性的字段或同一条示例代码被改成两个新值时进入冲突面板人工选择，其他改动直接合并；相同操作重复到达只处理一遍。
- 契约更新即时失效：属性契约（名称、类型、必填性）、交互签名或键盘行为更新后，依赖的示例立即标记失效。
- 主题与密度预览：支持浅色/深色，以及紧凑、标准、宽松三档密度。
- 代码示例复制与离线编辑：内容写入本地存储，刷新或断网后仍可继续编辑。
- 撤销重做：支持工具栏按钮，以及 `Cmd/Ctrl+Z`、`Shift+Cmd/Ctrl+Z`。
- 键盘流程：`Cmd/Ctrl+K` 聚焦搜索，`Alt+1` 至 `Alt+5` 切换编辑区，`Alt+N` 新建组件，`Cmd/Ctrl+S` 保存版本。

## 技术栈

- Lit 3
- TypeScript 5
- Spectrum Web Components
- Vite 7

## 开发

```bash
npm install
npm run dev
```

开发服务器默认在源码配置的 Vite 端口运行，并监听 `0.0.0.0`。宿主机端口由项目根目录的 `docker-compose.yml` 统一映射为 `10028:80`。

## 类型检查、测试与生产构建

```bash
npm run typecheck
npm test
npm run build
npm run preview
```

`npm test` 在 Node 中模拟两个共享 `localStorage` 的标签页，覆盖：顺序重放、逐字段合并、属性/示例代码冲突、冲突解决、重复操作去重、契约失效传播、撤销重放同步与快照合并。

生产文件输出到 `dist/`。

## Docker

```bash
docker build -t sologsb-1028 .
docker run --rm -p 10028:80 sologsb-1028
```

镜像采用 Node 多阶段构建，最终由 nginx 提供静态内容并监听容器 `80`。容器不硬编码宿主端口。

## 数据说明

浏览器存储键：

- `sologsb-1028-workspace-v2`：操作日志信封（重放基线 + 按 `(时间戳, 标签页内序号, 标签页 id, 操作 id)` 排序的操作数组）。组件目录、规范检查、版本快照与本地保存都从重放后的合并状态读取，不再保存任何单标签页的整份状态。
- `sologsb-1028-view-v2`：仅本标签页的视图状态（当前选中的组件），不参与跨页合并。

每条编辑操作携带全局唯一 id 与编辑前的字段值：相同 id 的操作无论被投递多少次只处理一遍；两个标签页基于同一旧值把同一属性字段或同一条示例代码改成不同新值时产生冲突，在顶部冲突面板选择后广播解决操作；其余改动互不阻塞，直接合并。首次打开会把旧版 `v1` 的整份状态迁移为 v2 基线后删除旧键。清除站点数据会恢复到内置示例数据。
